# 🚀 Featured Projects

## 🤖 [AI Study Companion](https://github.com/heena-jindal/AI_study_Companion)

An AI-powered study companion built around **LLMs, RAG, Agentic AI and evaluation**. The system generates quizzes from study material, tracks performance, identifies weak topics and uses an agent to autonomously select appropriate tools.

**Key concepts explored:**
- 📄 PDF ingestion and RAG
- 🧠 ChromaDB retrieval
- 🤖 LangGraph ReAct Agent
- 📝 Structured outputs with Groq + Pydantic
- 📊 SQLite-based learning history
- 🔍 LLM-as-a-Judge evaluation
- 🚀 Live deployment
